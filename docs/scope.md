# Supported features and explicit boundaries

This release prioritizes a working, auditable FLRW laboratory. It is not a complete simulation of all known or speculative astrophysics.

| Capability          | Implemented scope                                                                                                            | Boundary                                                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Numerical expansion | Adaptive RK with conservative fluid transfers                                                                                | No general implicit stiff solver                                                                                               |
| Recollapse | Stable constant-w/Λ fluids and closed CPL laws with wₐ<0 (closed-form ρde(a)), signed curvature/vacuum; turnaround and bounce | No general interacting contraction solver; closed CPL with transfers or custom events, open CPL with a halting negative dark energy and closed wₐ>0 turning early stop explicitly |
| Extreme time | Log-time, nested-log expansion, proven fluid tails; CPL continued by proof: dark-energy extinction (wₐ<0) and a quadrature-timed Big Rip (wₐ>0), labelled literal extrapolations of the fit ansatz | Arbitrary models stop at their numerical boundary, as do CPL laws whose proof conditions are not met or that custom w or vacuum events change |
| Dark energy | Λ, constant w, CPL (closed-form density), bounded, arithmetic custom | No dynamical scalar-field potential solver; the CPL future is a literal extrapolation of an observational fit, not a prediction |
| Dark matter         | Stable, decay, annihilation, warm pressure, H-proportional radiation transfer                                                | No microscopic particle inference or free streaming                                                                            |
| Neutrinos           | Future pressureless massive component plus effective radiation                                                               | No exact Fermi–Dirac background or perturbations                                                                               |
| Particle stability  | Optional exponential tracer survival                                                                                         | No baryonic decay feedback on Friedmann expansion                                                                              |
| Black holes         | Selected mass populations, ideal temperatures, mass loss and remnants; masses bounded by the Nariai and Hubble-radius masses | No spin, accretion, mergers, greybody rates, Schwarzschild–de Sitter evolution or absorption of horizon radiation              |
| Stellar future      | Broad event ranges and a logistic proxy                                                                                      | No IMF synthesis, white-dwarf/neutron-star counts or galaxy-merger prediction                                                  |
| Structure view      | Rotatable schematic 3D projected tracer groups                                                                               | Not an N-body simulation; no Big Rip bound-system thresholds                                                                   |
| Thermodynamics      | CMB/effective radiation T; de Sitter horizon entropy and Gibbons–Hawking temperature under an explicit de Sitter criterion   | No general event-horizon integral, horizon radiation in the background, or total entropy/free-energy budget                    |
| Event timing        | Equality and CMB/Hawking/de Sitter temperature crossings located on the continuous solution, each with its own sample        | Two crossings within one accepted step (Δln a ≤ 0.1; Δu ≤ 0.02 in the time domain) cancel; stellar and evaporation events are analytic or illustrative times |
| Uncertainty         | Seeded draws, covariance/posterior input, 68%/95% and selected intervals                                                     | No likelihood fitting or actual-fate probabilities                                                                             |
| Sensitivity         | Computed local finite differences                                                                                            | Not global Sobol indices or a universal parameter ranking                                                                      |
| Sweeps              | Two-dimensional bounded dark-energy grid                                                                                     | Not arbitrary higher-dimensional inference                                                                                     |
| Interventions       | Multiple timed events; some matched tails                                                                                    | Inconsistent or unsupported continuations stop explicitly                                                                      |
| Comparisons         | Four complete runs persisted in the browser, result-file import, export                                                      | First series overlaid for multiseries quantities; inspect/export full runs separately                                          |
| Provenance          | Reviewed, bundled primary-source registry and raw research snapshots                                                         | No automatic ingestion of new papers or posterior chains                                                                       |
| Reports             | JSON, CSV, SVG, PNG, Markdown and shareable configuration links                                                              | No PDF/Word generator or DOI registration                                                                                      |
| HTTP API            | `POST /api/simulate` for every analysis mode under a deterministic budget (10⁶ derivative evaluations, 64 runs, 11×11 sweeps, 64 KiB bodies) with explicit 400/413/422/500 codes | Heavier analyses belong in the browser worker or a local checkout; no authentication, queueing or result storage |
| Reproducibility     | Bit-identical reruns on Linux and Windows with Node.js 24 (platform-independent powers and tanh), deterministic example regeneration, golden master, property tests, work counters and an independent SciPy reference | CI recomputes every golden output with Node.js 24 on Linux and Windows. Newer V8 versions (for example Chrome and Edge 153) and other engines (Firefox, Safari) round exp, log, sin, cos and related functions differently. There the browser laboratory, and the HTTP API of the Cloudflare Workers build (workerd), reproduce committed outputs only approximately: in the last digits, and in a review with Chrome 153 and with workerd by up to 5% in log H beside a recollapse, where H nearly vanishes. They are not tested |

“Research software preview” describes this scope honestly. Successful unit tests are not external scientific peer review. Features beyond these boundaries require additional mathematical formulation and independent validation, rather than cosmetic controls with no physical implementation.
